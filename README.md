# Registro-de-Nuevos-Ingresos-BIC

Formulario web para el registro de nuevos ingresos BIC.

## Ejecutar

Requiere Node.js 18 o superior:

```bash
node server.js
```

Después abre `http://localhost:4173`. El servidor funciona como proxy para enviar los datos al flujo de Power Automate sin bloqueos CORS.
